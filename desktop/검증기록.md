# GHelper Profile Lab v0.3.1 변경 기록 · 2026-09-25

- 공개 자료실 검색창에서 한국어/영문 제품군·연도·GPU·CPU·메모리와 모델 코드를 조합해 검색할 수 있습니다. 카드·상세·게시 미리보기에 사람 친화적인 제품명과 확인된 기본 하드웨어를 표시합니다. 별칭은 ASUS 공식 사양의 모델 코드와 연결하며, 확인되지 않은 모델에는 제품명을 추정하지 않습니다.
- 검색 예: 제피러스 G16 2025 RTX 5090, GU605CX, Flow Z13 2025. 호환 기종 필터가 켜진 경우 다른 기종은 결과에서 제외됩니다.

이전 v0.3.0 검증 기록 · 2026-09-24

- Python 전체 테스트 **128개 통과**. 설정 검증·백업 복원·벤치마크 제어·트레이 수명·중복 실행·자료실 클라이언트·인증된 HTTP 경로를 포함합니다.
- 설정 시각화 JavaScript 테스트 **12개 통과**. 팬 곡선의 온도/백분율 해석, 모드별 값, Intel/AMD 구분, 0과 누락 값의 차이, GPU 클록 제한 초기화, 읽기 전용 동작을 확인했습니다.
- API의 실제 SQLite SQL·트랜잭션 회귀 테스트 **9개 통과**. 동시 재시도 중복 방지, 시간별 한도, 실패 롤백, 삭제 재시도, 커서와 크기 제한을 포함합니다. Cloudflare 전체 통합 테스트와 구분합니다.
- 메모리 전용 테스트 데이터로 자료실 열람·추가 목록, 동일 사양 설정 가져오기→적용 미리보기→적용, 다른 사양 적용 차단, 앱 내 게시 미리보기, 응답 유실 후 같은 요청 재전송과 중복 방지, 내 게시물 표시를 확인했습니다.
- 940×710 및 740×550 화면에서 내 설정·자료실을 확인했습니다. 가로 넘침과 JavaScript 오류가 없었고, 모드별 보기 전환이 설정 적용을 발생시키지 않았습니다. HTML 형태의 외부 메모는 글자로 표시됩니다.
- 최종 Windows EXE를 별도 데이터 폴더로 실행했습니다. 묶인 HTML·CSS·JavaScript가 최종 소스와 정확히 일치하며 실제 노트북 설정 감지, 공개 자료실 연결, 빈 개인 저장소, 정상 종료를 확인했습니다. 전용 창·트레이 수명은 자동 테스트로 확인했으며 최종 EXE의 모든 네이티브 클릭 동작을 수동 검증한 것은 아닙니다.
- `https://ghelper.optiwork.co.kr`의 HTTPS·상태 조회·D1 공개 목록 응답을 확인했습니다. 최종 EXE에서도 목록을 불러왔습니다. 운영 서버에 사용자 설정이나 임의 벤치마크 기록을 게시하지 않았습니다.
- 배포 ZIP에는 실행 파일·사용 안내·검증 기록·라이선스·빌드 안내만 넣습니다. 배포 과정에서 압축 무결성·실행 파일 SHA-256 일치·허용 목록을 검사합니다.

실제 G-Helper 설정 변경이나 Time Spy 실행을 수행한 검증은 아닙니다. 점수는 사용자 제공 기록이며 설정의 성능·안정성을 인증하지 않습니다. 일반 Steam판의 자동 실행 제한과 수동 소음/RPM 기록 범위는 사용 안내에 설명되어 있습니다.
