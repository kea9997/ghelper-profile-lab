# GHelper Profile Lab v0.4.4 · 사용 안내

G-Helper의 기본 3개 모드 설정을 저장·비교·복원하고 Time Spy 결과를 기록하는 Windows용 비공식 보조 프로그램입니다. G-Helper 실행 파일·드라이버·BIOS를 수정하지 않습니다.

## 빠르게 사용하기

- **내 설정 → 현재 설정 저장**: 한 번 누르면 날짜 이름으로 저장됩니다. 이름·메모는 필요할 때만 펼쳐 적으세요.
- **저장한 설정 → 적용하기**: 안내에 따라 G-Helper를 잠시 종료하고 적용합니다. 적용 전 상태는 자동 백업됩니다.
- **성능 비교 → 3개 모드 비교 시작**: 화면에 지금 할 일이 나타납니다. 끝나면 모드별 점수 옆에서 소음·팬 속도를 기록하세요.
- **모드별 점수 비교**: 조용·균형·터보에 연결된 마지막 정상 결과의 그래픽 점수와 CPU 점수를 한 화면에서 봅니다. 설정이나 측정 시각이 다른 결과도 함께 표시하며, 한 모드만 다시 측정해도 나머지 모드의 점수를 유지합니다. 점수가 없는 모드는 **지난 점수 연결**에서 직접 측정한 결과를 선택할 수 있습니다.
- **Time Spy를 직접 실행한 경우**: 성능 비교에서 **지난 결과 가져오기** → 점수 옆 **설정 연결** → 측정 당시 저장 설정과 모드 선택 → 확인. 이후 설정 자료실에서 점수를 선택해 공유하세요. 직접 연결한 점수는 측정 당시 설정을 앱이 검증하지 못했음을 공개 메모에 표시합니다.
- **내 노트북**: 조용·균형·터보의 저장된 전력값과 팬 곡선을 읽기 전용으로 확인합니다.
- **설정 자료실 검색**: `제피러스 G16 2025 RTX 5090`처럼 제품군·출시 연도·GPU를 같이 입력하거나 모델 코드·CPU·메모리로 찾을 수 있습니다. 카드에는 제품명과 GPU·메모리가 보이고 상세 화면에 정확한 모델 코드와 CPU가 표시됩니다.
- **설정 자료실 → 설정 보기 · 적용**: 다른 사용자가 올린 설정을 보고 ‘이 설정 사용’으로 가져온 뒤 적용 미리보기를 확인합니다.
- **설정 자료실 → 내 설정 공유**: 저장한 설정과 점수 선택 → 공개 내용 확인 → 앱 안에서 게시 순서입니다.

사양·연결 경로는 오른쪽 위 **도움말 · 설정**, 원본 수치는 각 항목의 **기술 정보**에서 확인합니다. 프로그램 창을 닫으면 트레이에 남습니다.

## 버전 확인과 업데이트

앱 창 상단의 제품명 옆에 현재 버전이 `v0.4.3`처럼 표시됩니다. **업데이트 확인** 버튼을 누르면 GitHub의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 변경 내용을 살펴보고 **업데이트 설치**를 선택하세요. 앱이 실행 파일의 SHA-256을 검증하고 재시작합니다. 보관한 설정·백업·점수는 `%LOCALAPPDATA%\GHelperProfileLab`에 남습니다.

성능 비교가 진행 중이면 마친 뒤 업데이트하세요. 실행 파일이 있는 폴더에 쓰기 권한이 없거나 자동 설치가 실패하면 릴리스 페이지에서 직접 받아 설치할 수 있습니다. v0.3.4 이하에는 업데이트 버튼이 없으므로 첫 한 번은 수동 설치가 필요합니다.

## 실행

`GHelperProfileLab.exe`를 실행하면 브라우저 창 없이 작업 표시줄 우측 하단의 트레이에 상주합니다. Windows가 아이콘을 숨겼다면 시계 옆 ∧(숨겨진 아이콘 표시)를 확인하세요.

- 트레이 아이콘을 클릭하거나 우클릭 → **Profile Lab 열기**: 전용 프로그램 창을 엽니다.
- 창의 **×** 또는 최소화: 트레이로 숨깁니다. 진행 중인 작업은 계속됩니다.
- 트레이 메뉴 또는 화면의 **종료**: 프로그램과 아이콘을 완전히 종료합니다. 벤치마크 진행 중에는 종료를 막습니다.
- 실행 파일을 다시 실행해도 중복 상주하지 않고 기존 창을 엽니다.
- 창을 바로 띄우려면 `GHelperProfileLab.exe --show`로 실행할 수 있습니다.

Python 설치는 필요하지 않습니다. 전용 창에는 Microsoft Edge WebView2 Runtime이 필요합니다. 없다면 Microsoft 공식 Runtime을 설치하세요. Windows 로그인 시 자동 실행 등록은 하지 않습니다.

전용 화면은 127.0.0.1의 로컬 서버를 사용합니다. 앱 안의 자료실은 [ghelper.optiwork.co.kr](https://ghelper.optiwork.co.kr)에 연결하며, 공개 확인 없이 내 설정을 자동 업로드하지 않습니다. 출처·배포 링크를 누르면 외부 브라우저가 열립니다. 개별 JSON 파일의 내보내기·가져오기도 계속 사용할 수 있습니다.

첫 배포 파일은 코드 서명이 없는 시험판입니다. 이 파일을 신뢰할 수 있는지 Windows가 확인할 수 없다는 메시지가 표시될 수 있습니다. Windows 보안 기능을 끄지 마세요. 소스 코드가 함께 제공됩니다.

업데이트는 [GitHub 최신 릴리스](https://github.com/kea9997/ghelper-profile-lab/releases/latest)에서 받습니다. 진행 중인 성능 비교를 마치고 기존 버전의 트레이 메뉴에서 ‘종료’를 선택한 뒤 새 파일을 실행하세요. 구버전이 남아 있으면 새 파일을 실행해도 기존 창이 열릴 수 있습니다. 실행 파일 교체 시 로컬 저장소를 삭제할 필요는 없습니다.

## 현재 설정 화면 읽기

‘내 노트북’의 모드 버튼은 **살펴볼 설정을 선택하는 읽기 전용 버튼**입니다. 이 화면에서 조용·균형·터보를 골라도 노트북의 실제 동작 모드는 바뀌지 않습니다. 앱을 열거나 값을 조회하는 것만으로 기본 설정을 변경하지 않습니다. 실제 모드 전환은 성능 비교를 직접 시작할 때 별도로 진행합니다.

전력값은 G-Helper 설정에 저장된 값이며 실측 소비 전력이 아닙니다. 값이 없으면 기본 동작으로 표시하고 임의의 와트 수를 채우지 않습니다. 자동 적용 표시가 켜져 있어도 해당 기기·BIOS가 그 항목을 지원하고 실제로 반영했음을 인증하는 것은 아닙니다. 다른 플랫폼용으로 남은 저장값은 현재 기기의 적용 항목과 구분하여 표시합니다.

팬 곡선의 가로축은 온도 °C, 세로축은 팬 속도 **%**입니다. 이 %는 실측 RPM이 아니며, 온도별 저장된 설정 곡선을 보여줍니다. 실제 회전수와 동작은 기기·BIOS에 따라 달라질 수 있습니다. 사용자 입력의 형식·범위 검사와 하드웨어가 실제 지원하는 범위는 서로 다릅니다.

## 설정 저장과 복원

1. 프로그램이 노트북과 G-Helper 설정을 자동으로 찾습니다. 연결 문제가 있으면 ‘도움말 · 설정’을 확인합니다.
2. ‘내 설정 → 현재 설정 저장’으로 조용·균형·터보의 지원되는 튜닝 항목을 저장합니다. 이름을 비워도 날짜로 저장됩니다.
3. ‘파일 가져오기’로 설정 JSON을 가져오거나, 앱 자료실의 ‘설정 보기 · 적용 → 이 설정 사용’으로 설정을 가져옵니다. 가져온 뒤 적용 미리보기에서 변경 사항을 확인합니다. 모델·CPU·GPU가 일치하지 않으면 적용을 막습니다.
4. 적용·백업 복원 전에는 G-Helper 트레이 메뉴에서 직접 종료합니다. 적용 후 G-Helper를 다시 실행하세요.
5. 적용 직전 전체 config.json이 자동 백업됩니다. 복원은 원본 바이트를 그대로 되돌립니다. 미리보기 이후 설정이 바뀌었으면 다시 확인해야 합니다.

공유 대상은 기본 3개 모드의 팬 곡선·CPU 전력·부스트·Windows 전원 모드·지원되는 NVIDIA GPU 설정입니다. 단축키 실행 명령, 장치 식별 번호, 로컬 경로, 서비스 설정, 화면·키보드 설정은 공유 프리셋에 넣지 않습니다. 커스텀 3번 이상 모드와 언더볼트는 이번 버전에서 다루지 않습니다. 누락된 지원 튜닝 키는 적용 시 기존 값에서 제거하여 G-Helper 기본 동작을 사용하게 합니다. 나머지 개인 설정은 유지합니다.

값의 형식·범위를 검사하지만 모든 기기에서 같은 성능이나 안정성을 보증하지 않습니다. BIOS·G-Helper 버전은 저장하되 동일 CPU/GPU만으로 버전 간 호환성을 보증하지 않습니다. 인터넷 참고 항목에는 자동 적용 버튼이 없습니다.

## Time Spy 3개 모드 비교

- 충전기를 연결하고 G-Helper를 실행한 상태에서 시작합니다.
- 조용(2) → 균형(0) → 터보(1) 순서입니다. **현재 각 모드에 저장된 값**을 사용합니다. 최적값을 자동 탐색하지 않습니다.
- 각 모드 전환 후 기본 120초를 기다립니다. 현재 대기는 고정 시간이며 온도에 따라 대기 시간을 조절하는 기능은 없습니다.
- **일반 Steam판 / 자동 실행(기본):** 프로그램이 모드를 전환하고 3DMark의 Time Spy 기본 테스트를 화면에서 확인한 뒤 실행 버튼을 자동으로 누릅니다. 엔진 실행·종료와 새 결과 저장을 확인한 후 다음 모드로 진행합니다. 3DMark 창을 열어 둔 상태에서 다른 창을 조작하지 마세요.
- **일반 Steam판 / 직접 실행:** 3DMark 화면 구조가 달라 자동 선택이 실패할 때 고급 옵션에서 선택할 수 있습니다. 각 모드에서 Time Spy 기본 테스트 실행 버튼을 직접 누릅니다.
- **Enterprise / 구 Professional:** 공식 `3DMarkCmd.exe`와 유효한 라이선스가 있으면 자동 실행합니다. CLI나 timespy.3dmdef를 찾지 못하면 실행하지 않습니다.
- 모드 전환은 G-Helper가 제공하는 기본 Ctrl+Shift+Alt 단축키를 사용하고 설정 파일의 모드 변경을 확인합니다. 권한 차이로 실패하면 G-Helper와 프로그램의 실행 권한 수준을 맞춰야 합니다. G-Helper가 관리자 권한이면 사용자가 필요 시 프로그램도 ‘관리자 권한으로 실행’할 수 있습니다. 자동 권한 상승이나 강제 종료는 하지 않습니다.
- 테스트 중 설정·모드 변경, 충전기 분리, 결과 실패를 확인하면 세션을 중단합니다. 3DMark가 아직 실행 중이면 사용자가 테스트를 종료한 뒤 원래 모드로 복원합니다. 앱 비정상 종료·재부팅 후에는 복구 알림을 표시하므로 G-Helper에서 원래 모드를 직접 확인하세요.
- 테스트 중 수집한 설정과 점수만 연결합니다. 설정 해시는 무결성 연결 용도이며 공식 성능 인증이나 위변조 방지 서명이 아닙니다.

기존 결과는 ‘과거 결과’로 가져오며 당시 설정을 앱이 자동 검증할 수 없습니다. 사용자가 측정 당시 저장 설정과 모드를 직접 확인해 연결하면 미검증 표시와 함께 공유할 수 있습니다. 실패·중단 결과의 0점도 정상 성능으로 취급하지 않습니다. 새 테스트의 원본 결과는 로컬에 따로 보관합니다.

점수 화면과 공유 PNG에서는 **그래픽 점수를 크게, CPU 점수를 그 아래에** 표시합니다. 종합 점수는 표시하지 않지만 원본 결과와 기존 공유 데이터의 호환성을 위해 내부 기록에는 남깁니다. 외부 참고 자료에 그래픽·CPU 점수가 없으면 미공개로 표시합니다.

## RPM·소음 기록

팬 RPM·소음 dBA는 **직접 측정해 입력**합니다. 소음 측정 거리, 주변 소음, 실내 온도, 거치대, 전원 상태는 메모로 남기세요. 불명확한 센서 단위는 추정하지 않으며 실시간 센서 자동 수집은 이번 버전에 없습니다.

## 앱 안에서 자료실 사용하기

‘설정 자료실’에서 [ghelper.optiwork.co.kr](https://ghelper.optiwork.co.kr)에 게시된 설정을 사용합니다. 별도 웹 업로드 화면을 거칠 필요가 없습니다.

1. **찾기:** 기본으로 ‘내 사양과 같은 설정만’을 표시합니다. 다른 기종을 둘러보려면 이 선택을 해제하세요. 검색창은 현재 불러온 목록에서 설정 이름·모델·작성자·메모를 찾습니다. ‘더 불러오기’로 다음 게시물도 불러올 수 있습니다.
2. **설정 보기:** ‘설정 보기 · 적용’에서 노트북 사양, 사용자 점수·소음 기록, 저장된 전력값과 팬 곡선을 확인합니다. 이 창의 모드 선택도 읽기 전용입니다.
3. **가져와 적용하기:** 사양이 맞으면 ‘이 설정 사용’을 선택합니다. 먼저 로컬에 가져온 뒤 적용 미리보기로 이어집니다. 변경 사항을 확인하고 G-Helper를 직접 종료한 뒤 적용하세요. 적용 직전 백업하며, 적용이 끝나면 G-Helper를 다시 실행해야 합니다.
4. **직접 공유하기:** ‘내 설정 공유’에서 저장한 설정, 작성자 표시 이름, 함께 공개할 정상 결과를 선택합니다. 공개 미리보기를 확인한 뒤 ‘자료실에 게시’를 누릅니다. 점수 첨부는 선택 사항이며, 설정과 연결되지 않은 과거 결과는 첨부할 수 없습니다.
5. **실패한 업로드 다시 확인하기:** 연결이 끊겨 완료 여부가 불분명하면 ‘내가 공유한 설정 → 업로드 다시 확인’을 사용합니다. 앱이 보관한 동일 요청으로 재시도하여 중복 게시를 방지합니다. 이전 요청을 확인하기 전에 같은 설정을 새 게시물로 반복해서 올리지 마세요.
6. **내 게시물 삭제하기:** ‘내가 공유한 설정 → 게시 취소’에서 확인 후 ‘게시물 삭제’를 누릅니다. 공개 게시물만 내려가고 이 컴퓨터에 저장한 설정은 남습니다.

게시 요청과 삭제 키는 전송 전에 **로컬 영수증으로 자동 보관**합니다. 별도의 삭제 키 파일을 내려받는 과정은 없습니다. 이 컴퓨터의 로컬 영수증으로 게시와 재시도를 관리하므로 저장소를 삭제하거나 다른 컴퓨터를 사용하면 기존 글의 삭제 키를 이용할 수 없을 수 있습니다. 키는 서버가 재발급하지 않습니다. 삭제 키나 영수증은 공유하지 마세요.

게시물은 서버 DB에 저장되며 다른 사용자가 앱 안에서 설정을 확인하고 가져올 수 있습니다. 작성자 표시 이름을 선택할 수 있고, 모든 기록은 사용자 제공 자료로 표시합니다. 공개 대상은 프리셋 이름·메모, 제조사·모델·CPU·GPU·메모리 용량·BIOS 및 G-Helper 버전, 허용된 튜닝 설정, 선택한 결과의 점수·날짜·모드·RPM·소음·메모입니다. 소스 결과 파일·로컬 경로·장치 시리얼·전체 G-Helper 설정은 업로드하지 않습니다. 자유롭게 작성한 메모에는 개인정보를 적지 마세요.

## 보관 위치·개발

- 기본 로컬 보관 위치: `%LOCALAPPDATA%\GHelperProfileLab`. 프리셋·백업·결과와 게시·삭제 영수증을 보관하므로 이 폴더 전체를 공개하지 마세요.
