# G-Helper Profile Lab

ASUS 노트북의 G-Helper 설정을 저장·비교·복원하고, Time Spy 결과와 함께 공유하는 Windows 트레이 앱입니다.

**[최신 Windows 버전 다운로드](https://github.com/kea9997/ghelper-profile-lab/releases/latest)** · [소스와 개발 안내](BUILDING.md)

릴리스의 `GHelperProfileLab-windows-x64.zip`을 풀고 `GHelperProfileLab.exe`를 실행하세요. Python 설치는 필요하지 않습니다. 설정 관리에는 별도로 설치한 G-Helper가 필요하고, 성능 비교에는 3DMark도 필요합니다. 전용 창에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## 자료실에서 기종 찾기

검색창에서 제품명과 기본 사양을 같이 입력할 수 있습니다. 예: `제피러스 G16 2025 RTX 5090`. 게시 카드에는 확인된 제품군·연도·GPU·메모리를, 상세 정보에는 정확한 모델 코드와 CPU를 표시합니다. `GU605CX`, `RTX5090`, `Core Ultra 9 285H` 같은 모델 코드·GPU·CPU 검색도 지원합니다.

앱과 웹의 기종별 참고 자료에는 [ASUS의 2024 GPU 전력 사양표](https://rog.asus.com/us/articles/rog-gaming-laptops/the-complete-list-of-geforce-gpu-power-specifications-for-2024-rog-and-tuf-gaming-laptops/)와 [2025 사양표](https://rog.asus.com/ca-en/articles/rog-gaming-laptops/the-complete-list-of-geforce-gpu-power-specifications-for-2025-rog-and-tuf-gaming-laptops/)의 모델별 기록, 원문에서 설정 조건과 점수가 함께 확인된 Time Spy 사용자 기록이 있습니다. 같은 검색창으로 모두 찾고 원문을 열 수 있습니다. 공식 GPU 전력은 기기 사양이지 G-Helper에 입력할 추천 수치가 아니며, 참고 항목은 자동 적용되지 않습니다.

## 처음 사용하기

앱은 작업 표시줄 오른쪽 트레이에서 시작합니다. 아이콘이 보이지 않으면 시계 옆 숨겨진 아이콘을 확인하세요. 트레이의 **Profile Lab 열기**로 창을 열고, **×**나 최소화는 트레이로 숨깁니다. 완전히 끝내려면 트레이 메뉴의 **종료**를 선택하세요. 실행 파일을 다시 실행하면 기존 창이 열립니다.

| 하고 싶은 일 | 앱에서 할 일 |
| --- | --- |
| 현재 설정 살펴보기 | **내 노트북**에서 조용·균형·터보 모드의 저장된 전력 제한과 팬 곡선 확인 |
| 버전·업데이트 | 창 상단에서 버전을 보고 **업데이트 확인 → 업데이트 설치** |
| 설정 보관하기 | **현재 설정 저장**으로 이름·메모와 함께 저장 |
| 다른 사용자 설정 살펴보기 | **자료실**에서 모델 필터로 찾고 미리보기 |
| 설정 적용하기 | 변경 사항과 모델·CPU·GPU 일치를 확인한 뒤 적용 |
| 내 설정 올리기 | 저장된 설정과 연결된 결과를 골라 공개 내용을 확인하고 게시 |
| 게시 취소하기 | **내 게시물**에서 로컬에 보관된 삭제 키로 삭제 |
| 점수 자랑하기 | **성능 비교 → 내 점수 이미지 저장**으로 3개 모드 점수 카드를 PNG로 저장 |

현재 설정 화면은 읽기 전용입니다. 앱을 열거나 모드·전력·팬 곡선을 조회하는 것만으로 기본 설정을 바꾸지 않습니다. 저장되지 않은 수치를 임의의 전력값이나 팬 속도로 추정하지 않습니다.

적용을 직접 선택하면 지원되는 G-Helper 설정 항목을 변경합니다. 앱 안내에 따라 G-Helper를 잠시 종료하고, 적용 후 다시 실행하세요. 적용 직전 전체 설정 파일을 자동 백업하며 모델·CPU·GPU가 맞지 않는 설정은 적용을 막습니다. G-Helper 실행 파일이나 BIOS는 수정하지 않습니다.

## 앱 안의 자료실

자료실은 [ghelper.optiwork.co.kr](https://ghelper.optiwork.co.kr)에 연결되어 있습니다. 웹에서 프로그램 소개와 공개 설정·점수를 검색해 볼 수 있습니다. 앱 안에서는 모델별 목록과 설정을 미리 본 뒤 적용할 수 있습니다. 인터넷 조사 자료는 출처를 살펴보는 참고 항목이며 적용용 프리셋과 구분됩니다.

게시 전에 공개할 작성자 이름, 모델 정보, 메모, 설정, 결과를 확인합니다. 확인 없이 자동 업로드하지 않습니다. 게시 요청과 삭제 키는 로컬에 먼저 저장하므로 응답을 받지 못한 요청은 같은 내용으로 재시도할 수 있습니다. 삭제 키는 다른 사람에게 공유하지 마세요. 키를 잃어버리면 앱에서 해당 게시물을 삭제할 수 없습니다.

공개 파일은 허용한 항목만 포함합니다.

- 작성자 표시 이름, 프리셋 이름과 메모
- 제조사·모델·CPU·GPU·메모리 용량·BIOS 및 G-Helper 버전
- 기본 3개 모드의 지원되는 튜닝 설정과 설정 해시
- 연결된 정상 테스트의 점수·모드·날짜, 직접 입력한 소음·RPM·결과 메모

장치 시리얼, 로컬 경로, 전체 G-Helper 설정, 단축키 실행 명령, 서비스 설정, 원본 결과 파일은 업로드하지 않습니다. 메모는 작성한 그대로 공개될 수 있으므로 개인정보를 적지 마세요. 프리셋·백업·삭제 키를 포함한 로컬 저장소 전체를 공유하지 마세요.

공유된 설정과 점수는 사용자 제공 기록입니다. **설정 해시는 설정과 결과의 연결을 확인하는 값이며, 공식 성능 인증이나 위변조 방지 서명이 아닙니다.** 같은 모델이어도 BIOS·드라이버·냉각 상태에 따라 결과가 달라질 수 있습니다.

## 3DMark 비교와 소음 기록

충전기를 연결하고 G-Helper를 실행한 상태에서 비교를 시작합니다. 현재 저장된 조용 → 균형 → 터보 설정을 사용하며, 모드 전환 뒤 기본 120초를 기다립니다.

| 3DMark 종류 | 실행 방식 |
| --- | --- |
| 일반 Steam판 / 실행 보조 | 앱이 모드를 전환하고 3DMark를 엽니다. **각 모드에서 사용자가 Time Spy 실행 버튼을 직접 누릅니다.** 새 결과를 확인하면 수집하고 다음 모드로 진행합니다. |
| Enterprise / CLI 지원 라이선스 | 공식 `3DMarkCmd.exe`와 필요한 테스트 정의 파일이 있으면 CLI로 자동 실행합니다. |

**팬 RPM과 소음 dBA는 직접 측정해 입력합니다.** 주변 소음, 측정 거리, 실내 온도, 전원과 거치 상태는 메모로 남길 수 있습니다. 실제 센서의 자동 측정값으로 표시하지 않습니다. Time Spy를 직접 실행한 결과는 **성능 비교 → 지난 결과 가져오기 → 설정 연결**에서 측정 당시 사용한 저장 설정과 모드를 직접 확인한 뒤 공유할 수 있습니다. 이 점수는 설정이 자동 검증된 결과로 표시하지 않습니다.

Time Spy 점수는 **그래픽 점수를 중심으로, CPU 점수를 함께** 표시합니다. 종합 점수는 화면과 공유 PNG에 표시하지 않으며, 원본 결과와 기존 공유 데이터의 호환성을 위해 내부 기록에는 남깁니다. 그래픽·CPU 점수가 원문에 없는 외부 참고 자료는 각각 미공개로 표시합니다.

성능 비교에서 **내 점수 이미지 저장**을 누르면 같은 설정으로 측정한 조용·균형·터보 점수, 기종·CPU·GPU, 직접 입력한 소음·팬 속도를 1200×675 PNG로 저장합니다. 이미지를 만드는 과정에서 서버로 업로드하지 않으며, 기기 시리얼·파일 경로·설정값·메모는 이미지에 넣지 않습니다. SNS 게시는 저장한 파일을 직접 선택해 진행합니다.

## 업데이트와 시험판 안내

이 배포는 코드 서명이 없는 시험판입니다. Windows가 게시자를 확인하지 못할 수 있습니다. Windows 보안 기능을 끄지 말고 다운로드한 릴리스와 제공된 소스를 확인하세요.

v0.4.0부터는 창 상단에서 현재 앱 버전을 확인하고 **업데이트 확인**을 누를 수 있습니다. 새 정식 버전이 있으면 변경 내용을 확인한 뒤 **업데이트 설치**를 누르세요. GitHub 릴리스 실행 파일의 크기와 SHA-256을 확인하고, 앱을 종료한 뒤 현재 폴더의 실행 파일을 교체하여 다시 시작합니다. 성능 비교 중에는 업데이트할 수 없습니다. 인터넷 연결이나 현재 폴더 쓰기 권한이 없으면 릴리스 페이지에서 직접 받아 설치하세요. 자동 설치에 실패하면 이전 실행 파일을 복원하고 안내를 표시합니다.

v0.3.4 이하에서는 업데이트 버튼이 없으므로 [최신 릴리스](https://github.com/kea9997/ghelper-profile-lab/releases/latest)를 한 번 직접 받아야 합니다. 기존 버전의 트레이 메뉴에서 **종료**한 뒤 새 ZIP을 별도 폴더에 풀거나 실행 파일을 교체하고 다시 실행하세요. 이후부터 앱 안에서 업데이트할 수 있습니다.

로컬 저장소는 기본적으로 `%LOCALAPPDATA%\GHelperProfileLab`에 있습니다. 실행 파일을 교체해도 저장소를 지우지 않으면 보관한 프리셋·백업·게시 영수증을 유지합니다. Windows 로그인 자동 실행은 등록하지 않습니다.

## 개발

Windows 앱 소스는 `desktop/`, Cloudflare Worker API는 `api/`에 있습니다. Python 3.14 이상·Node.js 24를 사용하며 [BUILDING.md](BUILDING.md)에 실행·테스트·빌드 명령이 있습니다. `scripts/build.ps1`은 PyInstaller 6.22.3으로 EXE와 문서·라이선스 포함 ZIP을 만듭니다. GitHub Actions는 테스트와 artifact 업로드만 수행합니다.

참고 자료 원본은 `desktop/catalog.manual.json`과 `scripts/generate_references.mjs`에 있습니다. 수정 후 `node scripts/generate_references.mjs`로 앱·웹 공유용 파일을 만들고 `node scripts/generate_references.mjs --check`로 일치 여부를 확인합니다. 근거가 없는 CPU·팬·Time Spy 값은 추가하지 않습니다.
